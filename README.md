# ShieldDefend: Phishing Awareness Program 🛡️

A modern, interactive, web-based training module designed to educate users about the dangers of phishing attacks, social engineering, and fraudulent websites. 

This single-page application (SPA) uses a sleek dark-mode aesthetic with glassmorphism elements to keep the learning experience engaging. It features integrated quizzes, real-world case studies, and practical security tips to reinforce cybersecurity best practices.

## ✨ Features

- **Interactive Quizzes**: Test your knowledge immediately after learning about a topic. Get instant feedback on your choices.
- **Scroll Reveal Animations**: Smooth entry animations for content as you scroll down the page, providing a dynamic learning experience.
- **Modern UI/UX**: Built with a premium dark theme, featuring glassmorphism cards (`backdrop-filter`), vibrant gradient accents, and dynamic background blobs.
- **Reading Progress Bar**: A visual indicator at the top of the screen tracking your progress through the training module.
- **Comprehensive Content**: Covers identifying threats, understanding social engineering (Spear Phishing, Whaling, Vishing, Smishing), real-world case studies, and prevention strategies.

## 🛠️ Technologies Used

This project is built purely with standard web technologies. No build steps, frameworks, or dependencies are required.

- **HTML5**: Semantic structuring of the training content.
- **CSS3**: Modern styling, Flexbox/Grid layouts, CSS variables, keyframe animations, and responsive design.
- **Vanilla JavaScript**: Logic for the interactive quizzes, progress bar calculation, and `IntersectionObserver` for scroll animations.
- **Google Fonts**: Uses 'Outfit' for headings and 'Inter' for body text.

## 🚀 How to Run

Since this is a static website, getting started is incredibly simple:

1. Clone or download this repository to your local machine.
2. Open the project folder.
3. Double-click on `index.html` to open it in your default web browser (Chrome, Firefox, Safari, Edge, etc.).

*No servers, databases, or package managers (like npm) are needed!*

## 📚 Module Structure

The training is broken down into the following key sections:

1. **Hero/Introduction**: An engaging overview featuring a mock phishing email example.
2. **Identifying Threats**: Learn how to spot the subtle signs of fake emails and malicious URLs.
3. **Social Engineering**: Dive into the psychology used by attackers (Spear Phishing, Vishing, etc.).
4. **Case Studies**: Analyze realistic scenarios ("The Fake Invoice", "The Urgent CEO Request") and their consequences.
5. **Prevention**: Practical, actionable tips (like enabling MFA) to secure your digital life.
